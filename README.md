# WifiShare (Personal Utility) 📶

A lightweight, minimal web utility created strictly for personal convenience to quickly share files, links, and connection details across local home devices without relying on third-party cloud apps or account sign-ins.

> ℹ️ **Personal Note:** This is a simple, unopinionated helper page built for personal household use across phones, laptops, and local devices on the same Wi-Fi network.

---

## 🎯 Purpose
* Quick peer-to-peer style asset and text exchange on the local network.
* Simple, browser-based interface with zero installation overhead.
* Offline / LAN-first utility to solve daily multi-device friction.

---

## 🚀 How to Run
Simply open `index.html` in any modern web browser, or serve locally using any simple HTTP server:

```bash
# Using Python
python -m http.server 8080

# Using Node (npx)
npx serve
```

---

## 🔒 Privacy & Scope
* Runs entirely client-side on the local network.
* No telemetry, no external database, no analytics.
